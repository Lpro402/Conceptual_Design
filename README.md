# Metalyte PRO-MPRO concept demonstrator

This repository is the temporary engineering workspace for an academic
software concept demonstrator of the Metalyte PRO-MPRO emergency EV
mobility-restoration system.

The demonstrator is not production firmware, a real EV charger, a CCS2
implementation, a functional-safety implementation, hardware-control
software, or a controller suitable for real electrochemical equipment.

The repository organization is not a product tree, PBS, BOM, ICD, or
N-squared model. Those artifacts belong to later systems-engineering stages.

Implementation and operating instructions are added in the second baseline.
