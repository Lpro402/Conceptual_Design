Control Twin · Configuration 2

The three feedback loops of the control design, below the state machine and the independent safety supervisor. The same reduced-order models run in Python (src/mpro/control_twin) with automated tests. Parameters are tuning placeholders, not validated plant values.

1 · Cascaded power / current loop

A fast inner current loop under a slower PI power loop with feed-forward. The reference is ramp-limited so the cartridge never sees a load jump; Boost to 12 kW is requested at t = 3 s.

2 · DC link stabilised by the LIC

The load steps from 10 to 12 kW at t = 2 s. The stack answers with an ohmic drop and a slow polarisation; the LIC carries the fast part around a slowly moving reference and hands the load back to the stack.

3 · Thermal / fluid loop

Feed-forward from the power command plus PI on core temperature. Boost is requested at 5 min; above 52 °C Boost is disabled, above 55 °C power derates.
