Metalyte PRO-MPRO · Digital Twins

Configuration 2 of alternative 1. One design baseline feeds every twin: the software twin runs the mission logic, the chemical twin is the cartridge plant it drives, the control twin closes the power, DC-link and thermal loops between them, and the integration twin rehearses the build-up and verification of the system. All values are conceptual Tier 0–1 design values, not test evidence.

SOFTWARE TWIN

Mission logic & operator HMI

  • 15-step Configuration 2 state machine
  • Environment check, vent confirmation, HVIL/CP/IMD, ISO 15118 → DIN 70121
  • FILL_SESSION: batch filling, valve closed until 1.8 L
  • LCD, architecture, diagnostics and service views
Open software twin
CHEMICAL TWIN

Al-air cartridge plant

  • 3D system and cartridge cutaway
  • KOH 4 M, 96 V stack, 10 kW / 12 kW Boost, 3 kWh
  • Mass balance, H₂, retained products, thermal envelope
  • Monitoring · diagnostics · prognostics · prescriptive layers
Open chemical twin
CONTROL TWIN

Feedback loops under the state machine

  • Cascaded power / current loop with ramp limit and anti-windup
  • DC link held by the LIC buffer against load steps
  • Thermal loop: power feed-forward + PI, Boost disable / derate
  • Interactive tuning with live step responses
Open control twin
INTEGRATION TWIN

Integration levels & gates

  • Hierarchical spine L0–L3 with functional threads T1–T7
  • Component, interface and environment simulators
  • GATE-IF, GATE-H2, GATE-HV and fault injection
  • Traceable CSV / JSON event log
Open integration twin
